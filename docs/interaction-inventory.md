# interaction-inventory — 挙動の棚卸しと分類

実サイトの挙動を実測し、**再現 / 近似 / 再現しない** を実装前に決めた記録。
ライブラリは1つも追加していない（②の Cocoon 移植で作り直しになるため）。

## 再現（自作・約100行の `assets/js/main.js`）

| 挙動 | 実サイト | クローンの実装 |
|---|---|---|
| **モバイルメニュー** | ≤768px でハンバーガー。全画面白パネル、右上 close(72×72)、項目高 70px、`Lato 16px/600/ls 2.4px`、下部にオフホワイト帯＋個人情報保護方針、背面スクリム `rgba(0,0,0,.16)` | 同じ。`aria-expanded` / Esc で閉じる / 背面スクロール固定を追加（原本にない**アクセシビリティ上の補強**であり、見た目は不変） |
| **スクロール表示** | `.appear` の付け外し。`opacity:0` + `translate: 0 12/24/48px`、罫線のみ `scale: 1e-10 1`。300–800ms / `cubic-bezier(0.4,0.4,0,1)` | `IntersectionObserver` で `is-revealed` を付与。同じ初期値・同じイージング。グループ内は 80ms ずつずらす |
| **固定背景の視差** | ヒーローと下部CTA帯に、同一の `position: fixed` 画像1枚が透ける | `position: fixed; inset: 0; z-index: -1` の写真1枚。上に載るグラデーションも同値 |
| **デモ表示の閉じるボタン** | （原本になし。クローン固有） | `position: fixed` で**本文レイアウトを1pxも動かさない**。`data-demo-notice` 付きで比較計測から除外される |

## 近似

| 挙動 | 差分 | 備考 |
|---|---|---|
| `.appear` の遅延 | 実サイトは要素ごとに 0 / 300 / 600ms の個別ディレイを持つ | クローンはグループ内 80ms ずつの一律スタッガー。**見え方はほぼ同じだが厳密には別** |

## 再現しない

| 挙動 | 理由 |
|---|---|
| **hover 効果** | **実サイトに無い**。リンク・ボタン・カードの hover 前後で背景色・透明度・transform が一切変化しないことを実測で確認済み。無いものは足さない |
| **フォーム送信** | 実サイトは `GET /contact`（STUDIO Form）。クローンは `action` を持たず、全項目 `disabled`、`submit` を JS で抑止。**実サイトの問い合わせ台帳に誤送信する経路を構造的に作らない** |
| Cookie バナー | 原本に無い |
| アクセス解析タグ | 原本に無い（個人情報保護方針には Google Analytics の記載があるが、実際のタグは未検出） |
| パンくず・検索・ページネーション | 原本に無い |
| お知らせ記事の詳細ページ | 原本に無い（3件中1件が外部PDFへのリンク、2件はリンクなし） |

## モーションの配慮

`prefers-reduced-motion: reduce` のとき、
スクロール表示のトランジションを停止し、固定背景（視差）を非表示にする分岐を入れてある。
これは**原本に無い追加**だが、見た目の初期状態は同じで、レイアウトは1pxも動かない。
